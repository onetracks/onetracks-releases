# OneTracks — Downloads

Baixe a versão mais recente do OneTracks para seu computador em [Releases](https://github.com/onetracks/onetracks-releases/releases/latest).

- **macOS:** `onetracks-macos.dmg`
- **Windows 64-bit:** `onetracks-windows-x64.zip`
- **Linux 64-bit:** `onetracks-linux-x64.tar.gz`

Os arquivos `SHA256SUMS.txt` contêm os checksums para verificar os downloads.
